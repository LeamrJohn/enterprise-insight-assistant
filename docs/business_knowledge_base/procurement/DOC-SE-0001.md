# 供应商年度评估报告

**报告编号：SUP-002-2025-AR**  
**评估周期：2024年度**  
**编制日期：2025年1月15日**


## 一、供应商概况与合作历史

深圳传动控制供应有限公司（供应商编码：SUP-002）位于深圳，主营传动控制类产品，为本公司该类目的核心供应商之一。自建立合作关系以来，该供应商持续承担传动控制产品的供应任务，合作历史稳定，未发生重大合作中断事件。

## 二、交付及时率与质量表现评估

本年度，SUP-002在交付及时率方面总体表现良好，常规订单均能按约定周期完成交付，未出现影响生产计划的重大延迟。在质量层面，该供应商年度综合质量评分为 **4.00/5.0**，处于良好区间。全年未发生批量性质量事故，个别批次出现的轻微质量问题均通过退货或换货方式妥善解决，未对下游客户造成实质性影响。

## 三、价格竞争力分析

在同类传动控制产品供应商中，SUP-002的报价处于中等偏上水平。尽管其单价并非市场最低，但考虑到其交付稳定性与质量表现，综合性价比仍具一定竞争力。建议在下一合作周期内，就其部分高单价型号进行专项议价，以进一步优化采购成本。

## 四、合作风险与改进建议

当前合作整体平稳，但仍存在以下需关注的风险点：

1. **价格波动传导风险**：该供应商对上游原材料价格变动较为敏感，曾两次提出调价申请，需在合同中进一步明确价格调整机制与上限幅度。
2. **质量持续改进空间**：4.00的质量评分虽属良好，但距离优秀（4.5以上）仍有差距，建议要求其提供年度质量改进计划及关键不良项的纠正预防措施报告。
3. **单一区域集中风险**：该供应商集中于深圳地区，建议适度引入备选供应商以分散区域集中风险。

## 五、续约或调整建议

综合评估，SUP-002在交付与质量方面均达到公司合格供应商标准，建议 **予以续约**，合作期限一年。同时建议在下一周期内完成以下调整：

- 签订年度框架协议，锁定价格调整上限；
- 设定质量评分提升目标（不低于4.3/5.0）；
- 每季度进行一次绩效回顾，动态跟踪改进落实情况。
