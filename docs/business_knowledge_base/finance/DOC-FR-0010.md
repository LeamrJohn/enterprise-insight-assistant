# 应收账款风险提示报告

**报告编号：AR-RISK-2024-023**  
**报告日期：2024年7月15日**  
**报告部门：信用管理部**


## 一、应收现状描述

截至2024年7月15日，华北食品加工客户023（CUST-0023，NORTH区域）在我司的未收余额为**¥357,917.08**，涉及逾期发票**5张**。该客户应收账款账龄已全部超出信用期，逾期金额占其总应收比例达100%，情况需予以关注。


## 二、逾期原因分析

经核查，该客户逾期主要原因包括：其一，客户近期反馈其下游销售回款周期延长，自身资金周转承压；其二，客户内部财务审批流程调整，付款审批节点增加，导致付款延迟；其三，双方对部分发票的账务核对存在分歧，客户暂缓支付争议部分款项。


## 三、催收进展

我司已通过电话及邮件方式联系客户财务负责人共计**6次**，并于2024年6月28日向客户发出正式书面催款函。客户口头承诺于2024年7月底前支付其中**2张**发票对应款项（合计约¥120,000），但截至本报告出具日尚未收到实际付款。


## 四、坏账风险评估

综合评估，该客户逾期时间已超过**60天**，且催收承诺未兑现，存在一定坏账风险。鉴于客户经营正常、无破产或重大法律纠纷记录，初步判断坏账概率为**中等偏低**，但若8月中旬前仍无实质付款进展，风险等级将上调。


## 五、建议措施

1. **升级催收力度**：建议由区域销售经理协同信用管理部，于本周内安排一次客户现场拜访，明确付款时间表。
2. **暂停新增授信**：在逾期款项未清偿前，暂停该客户新增订单的信用额度释放。
3. **分期还款方案**：建议与客户协商签订分期还款协议，要求其先支付30%首付款（约¥107,375），余款分两期于60日内结清。
4. **动态跟踪**：每两周更新一次催收记录及客户经营动态，必要时启动法务介入程序。
