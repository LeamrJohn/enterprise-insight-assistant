# 应收账款风险提示报告

**报告日期：** 2025年7月  
**报告对象：** 财务部、销售部管理层  
**客户名称：** 华东医疗器械客户009（CUST-0009）  
**所属区域：** EAST区域  

## 一、应收现状描述

截至本报告出具日，该客户未收余额为人民币758,531.08元，涉及逾期发票共计8张。逾期金额占该客户全部应收账款的比重较高，且逾期时间跨度较长，已触发公司应收账款风险预警机制。

## 二、逾期原因分析

经初步核查，该客户逾期原因主要包括：  
1. 客户内部资金审批流程调整，付款周期延长；  
2. 部分发票存在信息核对不一致问题，导致客户暂缓付款；  
3. 近期医疗行业回款整体放缓，客户下游资金承压。

## 三、催收进展

目前已通过电话及邮件方式联系客户财务负责人，客户表示正在安排部分款项支付，但尚未提供明确的书面付款承诺。销售团队已同步跟进，暂未取得实质性回款突破。

## 四、坏账风险评估

综合考虑客户历史合作记录、当前沟通反馈及行业整体回款环境，该客户短期偿付能力存在不确定性。若逾期状态持续超过90天，坏账风险将显著上升，建议按期末余额的30%–50%计提坏账准备。

## 五、建议措施

1. 暂停对该客户的新增授信及发货，直至逾期款项清零或达成书面还款协议；  
2. 要求客户提供分期还款计划，并明确每期还款时间节点；  
3. 由区域销售总监牵头，联合财务部开展专项催收，必要时启动法务介入程序；  
4. 持续跟踪客户经营动态，每两周更新一次回款进展报告。
