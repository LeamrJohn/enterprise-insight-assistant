# 应收账款风险提示报告

**报告日期：** 2025年7月  
**报告对象：** 财务部、销售管理部  
**客户名称：** 华东医疗器械客户033（CUST-0033）  
**所属区域：** EAST区域

## 一、应收现状描述

截至本报告出具日，该客户未收余额为人民币 **¥314,246.42**，其中逾期发票共计 **4张**。逾期金额占未收余额比例较高，且账龄结构呈恶化趋势，需予以重点关注。

## 二、逾期原因分析

经初步核查，该客户逾期原因主要包括以下两方面：  
1. 客户内部付款审批流程调整，导致付款周期延长；  
2. 近期部分订单存在收货确认延迟，影响客户对账及付款安排。

## 三、催收进展

我司已通过电话及邮件方式与客户财务及采购部门进行多轮沟通，客户口头承诺将于近期安排部分付款，但截至目前尚未收到实际回款。销售端已同步跟进，暂未取得实质性突破。

## 四、坏账风险评估

鉴于该客户历史合作记录良好，且当前逾期金额尚在可控范围内，初步判断发生全额坏账的可能性较低。但若逾期状态持续超过90天，回款不确定性将显著上升，坏账风险需上调至中等水平。

## 五、建议措施

1. 暂停对该客户的赊销额度释放，改为现款或预付款方式交易；  
2. 要求客户提供书面还款计划，明确分期付款时间节点；  
3. 由销售负责人牵头，联合财务部在两周内完成一次现场对账及催收；  
4. 若逾期超过60天仍未改善，建议启动法务介入程序。

请相关部门予以重视，并协同落实上述措施。
