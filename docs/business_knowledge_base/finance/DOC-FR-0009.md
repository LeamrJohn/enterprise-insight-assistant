# 应收账款风险提示报告

**报告日期：** 2025年7月10日  
**报告对象：** 财务部、销售部  
**客户名称：** 华北汽车零部件客户019（CUST-0019）  
**所属区域：** NORTH区域

## 一、应收现状描述

截至报告日，该客户未收余额为人民币365,485.83元，涉及逾期发票共计4张。该客户为我司NORTH区域重点汽车零部件分销客户，历史合作记录良好，但近期回款节奏明显放缓，逾期金额占其全部应收账款的比例较高，需予以关注。

## 二、逾期原因分析

经初步核查，逾期原因主要集中于以下两方面：  
1. 客户下游整车厂结算周期延长，导致其资金周转承压，付款计划被动后移；  
2. 客户内部财务审批流程调整，付款审批节点增加，客观上延迟了发票处理时效。

## 三、催收进展

我司已通过电话及邮件方式与该客户财务及采购负责人进行多轮沟通，客户口头承诺将于近期安排部分付款，但截至目前尚未收到实际回款，亦未提供明确的书面还款计划。

## 四、坏账风险评估

综合客户历史信用记录、当前逾期时长及行业回款环境，初步判断该笔应收账款存在一定坏账风险，风险等级评定为**中等偏高**。若客户下游资金压力持续，后续回款不确定性将进一步上升。

## 五、建议措施

1. 要求客户于一周内出具书面还款承诺函，明确分期付款时间表；  
2. 暂停对该客户的新增授信额度及新订单发货，直至逾期款项得到有效清偿；  
3. 由销售部与财务部联合跟进，必要时提请区域经理介入高层沟通；  
4. 若逾期超过60天仍未改善，建议启动法务催收程序并评估计提坏账准备。

请相关部门予以重视并协同落实。
