# 应收账款风险提示报告

**报告日期：** 2025年7月11日  
**客户名称：** 西部物流自动化客户004（CUST-0004）  
**所属区域：** WEST区域  
**报告部门：** 财务部应收组

## 一、应收现状描述

截至本报告日，该客户未收余额为人民币390,308.98元，涉及逾期发票共计5张。上述款项均已超过合同约定账期，且逾期时间较长，已触发公司应收账款风险预警机制。

## 二、逾期原因分析

经与销售团队及客户初步沟通，逾期原因主要包括：客户下游项目回款延迟，导致其资金周转紧张；客户内部付款审批流程调整，付款节奏明显放缓；此外，双方对部分发票金额存在核对分歧，尚未完成对账确认。

## 三、催收进展

目前我司已通过电话及邮件方式与客户财务负责人进行多轮沟通，客户表示认可欠款事实，但未给出明确付款承诺。销售团队已同步跟进，暂未取得实质性回款突破，催收工作处于持续交涉阶段。

## 四、坏账风险评估

鉴于该客户逾期时间较长、欠款金额较大，且付款意愿及能力均存在不确定性，当前坏账风险等级评定为**中等偏高**。若未来两个月内仍无有效回款或还款计划，风险等级将进一步上调。

## 五、建议措施

1. **暂停新增授信**：在欠款结清前，暂停对该客户的新增赊销额度。
2. **制定还款计划**：要求客户提供书面分期还款方案，并明确首期还款时间。
3. **升级催收层级**：由区域经理及财务主管联合上门拜访，推动高层协商。
4. **准备法律途径**：若协商无果，建议在逾期满6个月时启动法务程序。
