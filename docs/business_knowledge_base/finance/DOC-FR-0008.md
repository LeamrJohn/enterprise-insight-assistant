# 应收账款风险提示报告

**报告日期：** 2025年7月10日  
**报告部门：** 财务部信用管理组  
**客户名称：** 华东精密制造有限公司（CUST-0001）  
**所属区域：** EAST区域  

---

## 一、应收现状描述

截至2025年6月30日，华东精密制造有限公司在我司的未收余额为**¥388,006.60**，涉及逾期发票**7张**。该客户应收账款账龄主要集中在60至120天区间，逾期金额占其总应收比例较高，已触发公司信用风险预警阈值。

## 二、逾期原因分析

经与销售团队及客户沟通初步了解，逾期原因主要包括：  
1. 客户下游订单回款周期延长，导致其资金周转阶段性紧张；  
2. 客户内部付款审批流程调整，付款节点延迟；  
3. 部分发票存在对账信息不一致问题，影响客户付款确认进度。

## 三、催收进展

我司已于2025年6月中旬向客户发出首次书面催款函，并于6月底进行电话催收。客户表示认可欠款事实，承诺于7月底前支付约50%逾期款项，其余部分分两期结清。截至目前，尚未收到任何承诺款项。

## 四、坏账风险评估

综合客户历史付款记录、当前逾期时长及承诺兑现情况，评估该客户坏账风险为**中等偏高**。若7月底承诺付款未兑现，风险等级将进一步上调，需考虑计提坏账准备。

## 五、建议措施

1. 持续跟进客户付款承诺，要求其提供书面还款计划；  
2. 暂停对该客户的新增信用额度及发货安排，直至逾期款项清零；  
3. 由区域销售总监牵头，协同财务部于7月中旬进行现场拜访对账；  
4. 若8月中旬仍未收到首期款项，建议移交法务部门启动正式催收程序。
