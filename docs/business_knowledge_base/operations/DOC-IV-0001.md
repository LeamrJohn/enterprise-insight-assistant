# 月度库存与物流简报

**报告期间：2025年5月**  
**编制部门：仓储物流部**  
**发布日期：2025年6月3日**

---

## 一、当前库存总览

截至2025年5月31日，全库库存金额为2,847万元，环比下降3.2%。整体库存周转天数为58天，较上月缩短4天，周转效率有所改善。其中，A类高值物资（占比约15%的SKU）贡献了72%的库存金额，周转天数维持在42天，处于合理区间。

## 二、重点关注品类

- **五金工具类**：库存金额680万元，周转天数达76天，高于全库均值，存在积压风险。  
- **电气元件类**：库存金额520万元，周转天数35天，周转良好，但部分进口品牌型号库存偏低。  
- **安全防护用品**：库存金额310万元，周转天数49天，整体平稳。

## 三、物流交付统计

5月总发货订单1,286笔，按时交付率94.6%，较上月提升1.2个百分点。平均订单交付周期为2.8天，较上月缩短0.3天。区域配送中心直发比例达68%，剩余32%经由中转仓调拨，中转调拨平均耗时1.9天，略高于目标值1.5天。

## 四、异常与预警

1. **滞销预警**：五金工具类中，23个SKU连续90天无出库记录，涉及库存金额约86万元，需尽快制定处理方案。  
2. **缺货预警**：电气元件类中，3款进口继电器及2款变频器型号库存低于安全阈值，预计可支撑天数不足7天，需紧急补货。  
3. **物流时效偏差**：中转仓调拨时效连续两个月超出目标，主要集中于华东区域配送中心，需排查分拣及运输环节瓶颈。

## 五、建议措施

1. 对五金工具类滞销SKU启动促销或跨仓调拨，力争下季度前将积压库存降低30%。  
2. 针对缺货预警型号，立即向供应商下达紧急采购订单，并同步评估替代型号的可行性。  
3. 优化华东区域中转仓的波次拣货计划，将调拨时效压缩至1.5天以内。  
4. 下月将库存周转天数目标设定为55天，并持续监控A类物资的周转变化。
