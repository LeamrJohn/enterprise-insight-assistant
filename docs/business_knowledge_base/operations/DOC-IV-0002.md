# 月度库存与物流简报

**报告期间：2025年6月**  
**编制部门：供应链管理部**  
**发布日期：2025年7月3日**

---

## 一、当前库存总览

截至2025年6月30日，公司整体库存金额为2,847万元，较上月环比下降3.2%。库存周转天数为58天，较上月缩短4天，略优于行业平均水平（62天）。整体库存规模处于合理区间，但结构性分化明显。

## 二、重点关注品类

1. **电气自动化类**：库存金额占比达32%，周转天数仅41天，为全品类最优，但部分进口品牌型号（如西门子S7系列）库存偏薄，存在潜在缺货风险。
2. **气动元件类**：库存周转天数为76天，显著高于整体水平，其中三个老款型号（累计库存金额约86万元）已连续90天无出库记录，初步判定为滞销品。
3. **低压电器类**：库存金额占比28%，周转天数52天，整体健康，但施耐德特定系列缺货率本月上升至6.8%。

## 三、物流交付统计

本月订单总数为1,286单，按时交付率为94.2%，较上月提升1.1个百分点。平均交付周期为2.6天（含备货及运输），其中华东区域时效最优（2.1天），西北区域时效偏慢（4.3天）。紧急订单占比12%，其按时交付率仅为81.5%，是整体交付水平的主要拖累项。

## 四、异常与预警

- **滞销预警**：气动元件类3个型号连续3个月无动销，涉及金额86万元，需尽快制定处置方案。
- **缺货预警**：电气自动化类2个进口型号库存低于安全阈值，预计可支撑天数不足7天，需立即启动补货流程（采购周期约4周）。
- **时效风险**：西北区域因合作物流商线路调整，6月交付时效环比延长0.8天，需关注是否持续恶化。

## 五、建议措施

1. 对滞销气动元件启动促销或退换货谈判，目标在2025年Q3末将相关库存压降50%以上。
2. 针对进口型号缺货风险，提前锁定采购订单并与供应商确认交期，同时评估替代型号的可行性。
3. 与西北区域物流商重新确认服务标准，必要时启动备选承运商评估。
4. 持续跟踪紧急订单交付流程，分析延迟根因，优化加急订单的内部协调机制。
